Topic: Adding support for customizing the dependency dir

Celarye (Sep 24 2026 at 12:51):

I am working on adding support for customizing the WIT package dependency directory path like:

wit_bindgen::generate!({ path: "../wit", deps: "../wit-deps" });

At the moment the deps directory is hardcoded in wit-parser's internal Resolve::_push_dir method:

fn _push_dir(&mut self, path: &Path) -> Result<(super::PackageId, PackageSourceMap)> {
    let top_pkg = self
        .parse_dir(path)
        .with_context(|| format!("failed to parse package: {}", path.display()))?;
    let deps = path.join("deps");
    let deps = self
        .parse_deps_dir(&deps)
        .with_context(|| format!("failed to parse dependency directory: {}", deps.display()))?;

    let (pkg_id, inner) = self.sort_unresolved_packages(top_pkg, deps)?;
    Ok((pkg_id, PackageSourceMap::from_inner(inner)))
}

I would solve this by adding deps: impl AsRef<Path> as a parameter to the internal _push_dir method.

My question is if I should update the public push_dir method as well or if I should create a new push_dir_with_deps method instead?

Another question is then how we actually use this. As wit-bindgen relies on Resolve::push_path.

I am of the opinion to have wit-bindgen use Resolve::push_dir_with_deps in case a user provided a custom value for deps and path is a directory.

We could of course update Resolve::push_path as well but that would break a lot of things.

Let me know what you guys think is the best way forward.
