Browser host (jco): how witgraph uses lastTaskGroup and whenIdle(groups)

  • Records the group of a node's run in the same turn as the call: packages/witgraph-loader/src/index.ts#L713-L718 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/packages/witgraph-loader/src/index.ts#L713-L718)
  • Waits on the last runs of given nodes only, or on the whole instance when no nodes are given: packages/witgraph-loader/src/index.ts#L730-L734 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/packages/witgraph-loader/src/index.ts#L730-L734)
  • The callback's contract, "what a stream group holds its claims until": crates/witgraph-web/src/plane.rs#L49-L52 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-web/src/plane.rs#L49-L52)
  • Both kinds of wait side by side: whole-instance quiet versus one stream group drained: crates/witgraph-web/src/plane.rs#L495-L508 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-web/src/plane.rs#L495-L508)

Same use case on wasmtime, through its public task group API

  • Tracks live groups with TaskGroupHook: crates/witgraph-runtime/src/plane.rs#L657-L716 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/src/plane.rs#L657-L716)
  • Takes each run's group from call.group(): crates/witgraph-runtime/src/plane.rs#L777-L786 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/src/plane.rs#L777-L786)
  • A stream group counts as drained once its members' groups have finished: crates/witgraph-runtime/src/plane.rs#L865-L881 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/src/plane.rs#L865-L881)
  • Whole-instance quiet uses poll_no_interesting_tasks, the counterpart of the plain whenIdle() already merged upstream: crates/witgraph-runtime/src/plane.rs#L882-L890 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/src/plane.rs#L882-L890)

Tests showing why whole-instance idleness isn't enough

  • A finished stream group drains and runs again while an endless stream keeps the instance busy forever.
    • Browser: packages/witgraph-loader/test/session.test.ts#L2583-L2614 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/packages/witgraph-loader/test/session.test.ts#L2583-L2614)
    • wasmtime: crates/witgraph-runtime/tests/integration.rs#L762-L811 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/tests/integration.rs#L762-L811)
  • Every run returns while its stream is still flowing, so a run's promise resolving says nothing about whether the node's work is over.
    • Browser: packages/witgraph-loader/test/session.test.ts#L2554-L2581 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/packages/witgraph-loader/test/session.test.ts#L2554-L2581)
    • wasmtime: crates/witgraph-runtime/tests/integration.rs#L734-L760 (https://github.com/sansmoraxz/witgraph/blob/96a560d8603475ae4e1c9c6530e6f27899812972/crates/witgraph-runtime/tests/integration.rs#L734-L760)
