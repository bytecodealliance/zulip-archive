Summary

Fixes #14671.

Defined tags use four-byte slots; an odd count can misalign the following pointer-sized func_refs and subsequent fields on 64-bit targets. Add align { ptr } between tags and func_refs in the shared VMContext layout.

Changes

  • Correct pointer alignment without unnecessary padding on 32-bit targets.
  • Add offset regression tests for 32/64-bit pointers and 0–3 defined tags.
  • Assert alignment of func_refs, startup_func_ref, and runtime_data_bases.
