Ensure that an error encountered when sending a request or response body is delivered to the associated transmit future when the body is coming from another host body which has been forwarded.

Previously a guest which forwards a request or response would have no way to see if the request/response body was delivered without error. For example, if the original sender passed a body with incorrect content length or if it dropped the connection before completion, the guest would still receive Ok(()) on the transmission future.
