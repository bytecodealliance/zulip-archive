alexcrichton opened PR #14755 from alexcrichton:fix-oom-resource to bytecodealliance:main:

This commit fixes an issue when OOM happens while inserting a host resource into the store. When this happens it could leave the preexisting tables in a slightly erroneous state where two that are intended to be kept in sync are no longer in sync, meaning that further use of the store, such as inserting more resources, might panic. The fix here is to handle an error and roll-back an insertion halfway done.

This additionally cleans up the tests a bit, removing a duplicate test and removing an unneeded component.
