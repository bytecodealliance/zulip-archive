This commit implements spec-mandated behavior of delivering task cancellation events to async-lifted callback-based tasks more eagerly. Specifically after the main lifted function runs, or after a callback runs, the return code of that iteration is ignored if there's a pending cancellation and the callback is immediately invoked with cancellation in this situation.

The relevant functions here are shifted around to consolidate some functionality and lump this all together.
