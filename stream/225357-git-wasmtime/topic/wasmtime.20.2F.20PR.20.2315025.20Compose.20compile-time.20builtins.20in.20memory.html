Wasmtime GitHub notifications bot (Oct 27 2026 at 09:09):

dyslexicsteak opened PR #15025 from dyslexicsteak:compose-in-memory to bytecodealliance:main:

Compose the main Wasm and its compile-time builtins directly with wasm_compose::graph::CompositionGraph instead of writing them to a temporary directory and running the file-based ComponentComposer. Only builtins registered on the CodeBuilder can be composed in.

This also skips composition when the main Wasm imports no builtin, and drops the tempfile dependency of the compile-time-builtins feature.

This resolves a security issue and fixes various filesystem path related bugs and also adds tests with more realistic name inputs.

Fixes #15024.
