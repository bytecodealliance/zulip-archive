alexcrichton opened PR #14683 from alexcrichton:optimize-ref-func to bytecodealliance:main:

This PR is a series of commits which ends up optimizing the ref.func implementation within Wasmtime to notably not require a hostcall and additionally not require any function lookups within the compiled function tables. There's a number of linked issues to poor performance of ref.func and while this isn't a truly "zero cost" implementation it is significantly faster than it otherwise is today. The same implementation as before, where the fields are unconditionally initialized, is used no matter what. Conditional initialization could be part of a later runtime refactoring, if needed.

Note: this is a draft PR since there's an open design question around the Cranelift side of things I'd like to discuss this coming Wednesday.
