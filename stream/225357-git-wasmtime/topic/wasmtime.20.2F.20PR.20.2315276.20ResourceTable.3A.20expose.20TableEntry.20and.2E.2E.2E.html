TableEntry is now pub, with pub methods as getters to its contents. Mutable access is only given to the entry item itself, which keeps the assurance that internal invariants can't be broken by the iter_mut accessor.

To aid debugging the ResourceTable, TableEntry contains the core::any::type_name<T>() of an entry. This adds 2 words (16 bytes) of overhead to each TableEntry, but this debugging concern has come up repeatedly over the years, so my personal judgement is that this is an acceptable cost.

ResourceTable::iter_mut has been changed to have Item = (u32, &mut TableEntry) and new ResourceTable::iter is the same iterator with Item = (u32, &TableEntry) for immutable access. Both iterators will never yield a tombstone, which is an internal implementation detail, and ensures that .iter{_mut}().count() == .len(). ResourceTable::iter_entries and iter_children have also been updated to yield TableEntry refs as appropriate.
