cranelift-entity had two unsafe blocks left, and neither needs to be unsafe.

PrimaryMap::into_boxed_slice turned the backing Box into a raw pointer and rebuilt a BoxedSlice with from_raw. It now constructs the BoxedSlice directly, and from_raw is removed since nothing else used it.

get_raw_mut already bounds-checks the index before the pointer arithmetic; wrapping_add and add produce the same pointer here. On x86-64 release builds the generated assembly is identical except that the GEP loses inbounds nuw. This function currently has no callers in the tree, so if you would rather see it deleted than kept, I am happy to do that instead.

With both gone, the crate now carries #![forbid(unsafe_code)].

Testing: cargo test -p cranelift-entity passes (60 unit tests, 2 doc-tests) and Miri is clean.
