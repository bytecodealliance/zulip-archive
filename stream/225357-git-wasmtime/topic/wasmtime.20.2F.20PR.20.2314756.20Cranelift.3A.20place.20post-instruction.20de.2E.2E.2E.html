cfallin opened PR #14756 from cfallin:fix-debug-tag-location to bytecodealliance:main:

In the case where a branch-veneer/constant island was placed immediately after a call (or any other instruction), post-position debug tags on that call were emitted into MachBuffer metadata with the post-island offset rather than the end-of-instruction offset from just before the call.

This caused erroneous breakpoint behavior when tags were lost on patchable call sites used for breakpoints in guest-debugging. It showed up on riscv64 where shorter branch ranges caused more frequent island emission.
