When lowering the result of a host function, we do the lowering on a separate fiber because it may call realloc which could yield and it's unsound for that to occur outside of a fiber.

But if we can determine from the result type that lowering will not realloc, then we can immediately lower in the host task future. This PR introduces that optimization.

I see a ~20% improvement in the benchmark for calling an async noop function which yields.
