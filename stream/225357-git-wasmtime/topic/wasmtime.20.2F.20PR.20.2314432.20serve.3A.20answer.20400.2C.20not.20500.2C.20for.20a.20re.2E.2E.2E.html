xia-chao edited PR #14432:

wasmtime serve answers 500 when a request has neither a URI authority nor a
Host header. The rejection happens before the guest runs, so the error now
carries the status the client should see, and serve reads it back, defaulting
to 500. That gives the 400 RFC 9112 section 3.2 asks for, and it is not
version-specific: an HTTP/1.0 request without Host gets the same 400.
wasi:http/service is untouched.
