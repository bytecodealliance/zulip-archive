Hi, I added some missing optimization rules:

  • x - (-y << z) = x + (y << z)
  • (x << y) | (z << y) = (x | z) << y
  • (x & y) & (x & z) --> (x & y) & z
  • and one commutative variant of an existing rule

Also added unit test cases for these rules, and blessed minor changes of tests.

Thank you.
