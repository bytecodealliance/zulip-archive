alexcrichton opened PR #15125 from alexcrichton:fix-panic to bytecodealliance:main:

This commit fixes a possible panic when translating a component when a module is imported and uses rec-group-defined types. The problem is that a module type's imports and exports could refer to types which weren't previously intern'd and would cause problems upon reaching them.

The main fix for this was landed in wasmparser already to expose the core index space in module types, and that's now used to intern everything found. This ensures that all types are always available when doing type translation.
