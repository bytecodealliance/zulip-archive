jrandolf opened PR #14838 from jrandolf:bindgen-map-param-ref to bytecodealliance:main:

For an exported function taking an anonymous map<K, V>, bindgen! generated a by-value HashMap of borrowed keys and values (e.g. HashMap<&str, &[String]>), so callers holding a HashMap<String, Vec<String>> had to build a second map of references to make a call. This mirrors how lists are handled instead: in borrowed positions the map is taken by reference, and with Ownership::Owning its keys and values are owned. Named map types already generated &Named.

This changes generated signatures, see #14831. It's based on #14834; only the last commit is new.

Closes #14831
