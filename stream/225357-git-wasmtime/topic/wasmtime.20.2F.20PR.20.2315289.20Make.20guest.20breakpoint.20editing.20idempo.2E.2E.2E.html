Fixes #15284

Fixes #15284. Editing breakpoints could panic when enumerating a component-exported module, leave a slipped breakpoint enabled after repeated adds and removes, or leave guest code unexecutable if the editor was forgotten.

Register module metadata even when its component already registered the shared code, record every distinct requested PC once while retaining reference counts for requests that slip to the same opcode, and restore executable permissions with a private guard inside each operation. This preserves the documented idempotent editing semantics; code publication now happens per operation rather than being batched until the editor is dropped.

Regression coverage exercises component exports, repeated and overlapping breakpoint requests, and execution after forgetting editors for add, remove, and single-step operations.
