alexcrichton opened PR #14558 from alexcrichton:fix-more-waitable-set to bytecodealliance:main:

  • Fix a spec-conformance issue where waitable sets prevent drop while something is waiting on them, not just blocked on them. For example if a thread is woken from a waitable set the waitable set can't be dropped until that thread has woken up to process the event.

  • Fix an issue where with threads a yield event from one thread could be stolen by another thread.

  • Fix situations where a waitable set's blocked thread is woken but by the time it runs the event it was supposed to receive was stolen by something else (e.g. a poll). In this situation threads generally just go back to sleep automatically without running more wasm.

This fixes a number of spec conformance issues as well as bail_bug!s that can be encountered otherwise.
