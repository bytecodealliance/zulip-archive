This script:

import sys
d, n = int(sys.argv[1]), 20000
print('(module (func (param i32) (result i32) (local i32)',
      'loop ' * d,
      'local.get 1', 'local.get 0 i32.add ' * n, 'local.set 1',
      ' '.join(f'local.get 0 br_if {k}' for k in range(d)),
      'end ' * d,
      'local.get 1))')

generates a module that takes a long time to compile:

d1000.wasm.txt
d2000.wasm.txt

$ python3 gen.py 1000 > d1000.wat
$ python3 gen.py 2000 > d2000.wat
$ time cargo run --release -- compile d1000.wat
13.56s
$ time cargo run --release -- compile d2000.wat
55.16s

Wasmtime 50.0.1 compiles each of them in about 0.1s.
