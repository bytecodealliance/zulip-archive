This commit is a migration of preexisting wasip1 tests in Wasmtime's test suite to the wasip2 target. The goal here is to lessen Wasmtime's dependence on the wasm32-wasip1 target in CI over time, but this is going to be a bit of a process. Currently all of Wasmtime's source-code-written tests are compiled for wasm32-wasip1 and then componentized optionally later with the adapter. I'd like to natively compile for wasm32-wasip2 eventually, but for now the goal is to shift away from p1-sourced tests.

Additionally Wasmtime has very little testing of wasip2 specifically. Instead all wasip1 tests are componentized with the adapter and run both as a core module and a component. This means that the coverage for wasip2 is basically the same as wasip1, but it also means that should the tests simply be deleted we'd lose wasip2 test coverage.

That brings us to this change. Here wasip1 tests are migrated to wasip2. The tests migrated here are already duplicated in the upstream WebAssembly/wasi-testsuite repository (where many tests came from Wasmtime originally), so this additionally isn't losing coverage for wasip1 either. For now the goal of this commit is to be coverage-neutral where wasip1 tests are shifted to being tested by wasi-testsuite, and wasip2 tests are preserved by manually writing against the wasip2 APIs.
