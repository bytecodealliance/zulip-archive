Add new mid-end optimization rules:

  • x << (k & (B - 1)) ==> x << k
  • x >>u (k & (B - 1)) ==> x >>u k
  • x >>s (k & (B - 1)) ==> x >>s k
  • uextend(x) <u uextend(y) ==> x <u y
  • x %s P == 0 ==> (x & (P - 1)) == 0 (constant power-of-two P > 0)
  • (x >=s 0) & (x <s N) ==> x <u N (constant 0 < N < 2^(B - 1))
  • x %u (1 << k) ==> x & ((1 << k) - 1)
