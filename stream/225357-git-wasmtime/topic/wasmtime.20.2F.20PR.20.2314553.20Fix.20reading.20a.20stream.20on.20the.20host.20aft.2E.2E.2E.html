This commit fixes a bail_bug! being hit when a guest partially reads data from a stream, doesn't receive the event on the writer side, and then the host tries to read the data itself on the stream. The fix here is to delay the host's read until the guest writer-half decides to do something else with the stream as opposed to immediately trying to read it which might end up needing to merge events which is not implemented.
