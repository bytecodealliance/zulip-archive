Closes https://github.com/bytecodealliance/wasmtime/issues/14496

Android's Seccomp policy prior API level 37 is to raise a fatal signal on openat2 syscall instead of returning ENOSYS, and it makes Wasmtime crash.
Recently released API level 37 finally allowed openat2 (see SECCOMP_ALLOWLIST_COMMON.TXT, it now includes openat2).

Device's API level needs check at runtime. I did my best to avoid dependency on ndk crate, so dlsym and some unsafe code is used to detect API level. CHECKED flag is inspired by crates/wasi/src/filesystem/primitives/unix/freebsd.rs.

Tested by running tests from wasmtime-wasi crate on real Android 13 (API level 33) device and x64 emulator of Android 17 (API level 37). Now all tests pass, with the exception of tests that can't run because Android's SELinux disallows hard links. Testing is done by AI and involved building Rust code using cargo-ndk, building an Android Gradle project just because running binary directly using adb shell applies slightly different Seccomp rules, and other dirty hacks, so I think I shouldn't include such test script. Some manual testing is done too.
