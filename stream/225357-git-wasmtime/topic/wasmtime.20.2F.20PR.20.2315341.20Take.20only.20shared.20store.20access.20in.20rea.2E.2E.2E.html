cfallin opened PR #15341 from cfallin:debug-readonly-apis to bytecodealliance:main:

Several APIs that only read a store's state take mutable access to it, which makes them unusable where only shared access is available, such as in an eventual record/replay/snapshot mechanism. Now that GC values can be read as Unrooted references, with only shared access, several more APIs can take impl AsContext instead of impl AsContextMut: getters on Instance for tables, memories, and globals; debug getters; the debug FrameHandle API; and Func::to_raw (which I'll use in tests in later PRs). To make the frame-handle bit work, we need internal locking for the FrameDataCache (which avoids re-parsing the frame table when frame handles are re-obtained at each debug event).
