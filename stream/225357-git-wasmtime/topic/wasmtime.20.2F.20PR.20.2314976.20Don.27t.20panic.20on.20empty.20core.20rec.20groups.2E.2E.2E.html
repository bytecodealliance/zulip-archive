An empty core rec group in a component panics Component::new, and wasmtime compile, with the default configuration. These all validate:

  • (component (core rec)) indexes out of bounds.
  • (component (core rec) (core type (module))) unwraps an Err(()).
  • (component (core type (sub (array i8))) (core rec)) indexes out of bounds.

The component translator found each core rec group from the type at the group's first index, which an empty group doesn't have, so it looked past the end of the core types or at the next definition's type. Empty rec groups define no types, so this skips them.

Found by fuzzing Wasmtime with components generated from the component model's binary grammar (bytecodealliance/wasm-tools#2796).
