Reading a numeric global never has to clone a GC reference, so it does not need AsContextMut. This adds Global::get_numeric(&self, impl AsContext) -> Option<Val>, returning None for reference-typed globals, so embedders can read numeric globals from the epoch and call hooks that only get StoreHookState after #14386.

Global::get now reuses the same numeric read, so there is no duplicated implementation. Tables are left alone for now.

Closes #14965
