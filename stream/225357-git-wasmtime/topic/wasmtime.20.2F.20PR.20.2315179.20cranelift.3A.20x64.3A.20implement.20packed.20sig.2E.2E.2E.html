Fixes #3296

Why

The x64 backend had no lowering for ssub_sat on i32x4 or i64x2. Since x86 has no packed signed saturating-subtraction instruction for those lane widths and there was no legalization fallback, these operations failed with an ISLE lowering error.

What changed

  • Add SSE2-based lowerings for i32x4 and i64x2 signed saturating subtraction.
  • Detect subtraction overflow per lane and select the appropriate MIN or MAX saturation value.
  • Update x64 fuzzgen so it no longer excludes ssub_sat for these types.
  • Extend and rename the regression test to cover AArch64, x86_64, x86_64 with AVX, and both RISC-V 64-bit configurations.
