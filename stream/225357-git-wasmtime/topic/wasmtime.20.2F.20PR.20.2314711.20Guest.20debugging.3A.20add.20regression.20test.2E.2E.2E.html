Issue #14609 reports a Wasmtime panic that occurs because, ultimately, a breakpoint in a Wasm start function triggered a bug in program-point lookup in metadata tables when a function (such as the compiled Wasm-module instantiation entry point) has no Wasm PCs.

This bug was recently fixed (after #14609 was reported) in #14677 due to an independent report of the issue, but this PR adds a regression test that directly mirrors the issue in #14609 to ensure that the fix stays tested.

Closes #14609.
