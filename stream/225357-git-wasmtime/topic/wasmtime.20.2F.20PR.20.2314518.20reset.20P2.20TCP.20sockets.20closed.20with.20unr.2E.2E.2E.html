Closing a P2 TCP socket with unread received data currently shuts down its retained streams before closing the native descriptor. The peer can therefore observe a clean EOF instead of the connection reset expected when closing a socket with unread data.

This PR resets connected sockets with unread data before their retained streams drop, using zero linger plus connect(AF_UNSPEC) on Linux/Android and disconnectx on Apple targets.
