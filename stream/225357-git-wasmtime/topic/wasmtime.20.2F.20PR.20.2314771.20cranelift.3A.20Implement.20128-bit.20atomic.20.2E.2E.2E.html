Depends on #14770

This adds and makes use of the CDSG instruction. Since the 128-bit integers are stored in VRs and CDSG operates on RegPairs, we need to introduce some helpers to move data between VRs and RegPairs by extracting or inserting two lanes of I64s.

I've verified this in qemu-user and on a z15 inside z/VM with the atomic-128 runtest, but we're missing an implementation of atomic_rmw before that can be enabled on s390x.

I'm not sure where to put these helpers, if there's a better place than lower.isle, which I suspect there may be, please let me know :)
