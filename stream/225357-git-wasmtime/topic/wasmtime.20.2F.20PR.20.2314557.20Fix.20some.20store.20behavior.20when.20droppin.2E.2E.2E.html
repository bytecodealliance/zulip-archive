This commit fixes a few issues when an async computation (a future) was dropped/cancelled on the host. This could lead to bail_bug! being hit in a number of locations which shouldn't be possible to hit. The general idea here is to lock down the store in a few more locations, for example cancelling a fiber, and then additionally shuffling around code around instantiation to move it to where it can't be interrupted via drop (no await points between the significant portions).
