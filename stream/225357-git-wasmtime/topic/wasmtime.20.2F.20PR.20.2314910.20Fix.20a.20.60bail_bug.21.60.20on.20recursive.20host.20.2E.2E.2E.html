This commit fixes a situation where a component calls the host, the host calls some other component which traps, and then the host returns to the original call normally. Previously this hit a bail_bug! since the stale state of the previous trapping component was still leftover and not fully cleaned up. The fix here is to prevent reentering components upon return if the store is flagged as having trapped.
