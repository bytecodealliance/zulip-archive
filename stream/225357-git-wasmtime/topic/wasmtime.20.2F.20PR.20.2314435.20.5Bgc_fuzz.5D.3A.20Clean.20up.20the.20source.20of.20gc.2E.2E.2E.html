Cleanups for the gc_ops generator, following up on the review of #14276.
No semantic change in emitted modules. I hashed the Wasm binary of the first 400 seeds before and after each step and all 400 stayed identical. Sorry if it looks like too many changes (I can split) but it is just code moves:

  • Replace the spelled-out heap types and the repeated table, global and null-guard instruction patterns with constants and small helpers.
  • Record every type and import index where it is created, so encode no longer restates the import order as literals.
  • Split to_wasm_binary into one helper per module section, and name the three typed local banks where they are declared.
  • Split encode into a dispatcher plus one function per op family, with all root reads and writes going through one encode_root keyed by a RefKind.
  • Split Types::fixup into named steps and rename the fixup family by what each one fixes (fixup_limits, fixup_types, fixup_immediates, fixup_operand).
  • Move StackType to its own file and collapse its operand fixup into one rule plus two lookup tables.
  • Add one-line docs to every function, field and variant
