Allow benchmarks to be measured by running under Callgrind. This is done by providing a utilities wasmtime_bench_util::bench and wasmtime_bench_util::Timer which are drop-in replacements for criterion::Bencher::iter and std::time::Instant respectively.

The goal of this change is to allow tracking of benchmark results in are-we-fast-yet.

When run natively, the utility replacements behave the same as iter and Instant, but when running under Callgrind they'll dump Valgrind counters when the timer is stopped.

Additionally, a helper function is provided which can be used to detect if the benchmark is being run under Valgrind and this is used for some benchmarks to reduce their memory usage to an amount Valgrind can support.

When using Valgrind, benchmarks should be run with Criterion's --test mode, so that each benchmark produces a single dump:

    valgrind --tool=callgrind --instr-atstart=no \
      target/release/deps/<bench> --bench --test
