Fixes #14691.

vrgather.vx uses the full scalar register as the vector index, but the upper bits of an i8/i16/i32 value are not guaranteed to be zero. Zero-extend the splat index before lowering so out-of-range upper bits cannot change the result.

Added RISC-V ISA expectations and a runtime regression test using a dirty upper byte.

Tests:

  • cargo run -p cranelift-tools -- test cranelift/filetests/filetests/isa/riscv64/simd-swizzle.clif
  • cargo run -p cranelift-tools -- test cranelift/filetests/filetests/runtests/simd-swizzle.clif
  • cargo fmt --all -- --check

The RISC-V runtime portion is covered by the QEMU CI job.
