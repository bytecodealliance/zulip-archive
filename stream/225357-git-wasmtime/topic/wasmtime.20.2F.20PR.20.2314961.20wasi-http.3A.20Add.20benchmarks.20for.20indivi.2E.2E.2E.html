Add a benchmark for each of the APIs request.new, response.consume-body or client.send. These are the most expensive calls made by an http proxy and so are useful to benchmark on their own.

The benchmarks are implemented by a cli Rust component which takes the API name and iters count as arguments. It then times itself calling the API iters times and prints the total time to stdout (in ns).
