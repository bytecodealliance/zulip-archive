Add mid-end optimization rules:

  • sextend(x) OP sextend(y) --> x OP y, where OP = {!=, >=s, <=s, >=u, >u, <=u, <u}
  • uextend(x) OP uextend(y) --> x OP y, where OP = {!=, >=u, <=u}
  • uextend(x) OPs uextend(y) --> x OPu y, where OP = {>=, >, <=, <}
  • (x != 0) | (y != 0) --> (x | y) != 0
  • (x == 0) & (y == 0) --> (x | y) == 0
  • select(c, C1, C2) OP C --> select(c, C1 OP C, C2 OP C), where OP = {|, ^, -}
  • C - select(c, C1, C2) --> select(c, C - C1, C - C2)
  • (x >> k) OP (y >> k) --> (x OP y) >> k, where OP = {&, |}
  • (x >>s k) & (y >>u k) --> (x & y) >>u k
  • ((x & M) << k) & M --> (x << k) & M, where M = 2^n − 1
  • ~x & (x | y) --> ~x & y
  • ~x ^ C --> x ^ ~C
  • ~(x & y) & (x | y) --> x ^ y
  • ~(x & y) | x --> -1

and revised some annotations.
