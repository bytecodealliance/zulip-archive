pchickey edited issue #15139:

The ResourcesRequired type, as obtained from Component::resources_required, is supposed to be used for "Determining whether your pooling allocator configuration supports instantiating this component."

At the moment there are several aspects that a pooling allocator configuration requires, but is not accessible through ResourcesRequired:

  • the maximum core instance size, and the number of core instances required to instantiate the component
  • the maximum component instance size, and total component instances
  • perhaps other items, this list will be expanded

The struct should be extended to include these aspects, and Component::resources_required will caluclate them.
