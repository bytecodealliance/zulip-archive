Prior to this commit embedder handles to futures/streams were effectively raw indices into tables. This means that incorrect usage on the embedder side is effectively entirely undetected and can have a wide array of varying consequences for usage. This is quite different from usage of guest resources, for example, which have more protections in place.

This commit switches the internal representation of future/stream handles to using the equivalent of what guest resources use. This provides a significant degree of insulation against mis-use via generational indices for example. Embedders with invalid usage should get errors much more quickly and the table IDs internally are generally able to be much more trusted now too.
