This is reachable even when the wasm GC_TYPES feature, which the Cargo gc feature gates, is disabled. For example the Cargo gc feature doesn't gate the wasm GC feature meaning that ref.test and such can still be used for functions with subtypes. Prior to this change the is_subtype libcall would simply abort the process when called from wasm code if the Cargo gc feature were disabled.
