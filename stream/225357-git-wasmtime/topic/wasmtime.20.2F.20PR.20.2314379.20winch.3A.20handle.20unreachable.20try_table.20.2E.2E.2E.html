macovedj opened PR #14379 from macovedj:winch-unreachable-try-table to bytecodealliance:main:

Compiling a try_table after an unconditional return currently fails with Invalid local offset, and with fuel enabled fails with Invalid fuel state. The first issue arises from Winch still registering its catches and attempting to emit landing pads, even though entering an unreachable block skips recording the stack state those handlers need. The latter comes from not skipping fuel accounting for unreachable control operators.

Winch now uses a plain block frame for a try_table entered in unreachable code, preserving nesting without registering catches. It also skips fuel accounting for unreachable operators while retaining the assertion that preceding reachable code flushed its pending charges.

Fixes #14377
