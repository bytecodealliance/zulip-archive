pchickey opened PR #15156 from pchickey:asan_compatible_config_option to bytecodealliance:main:

Starting in #14398, Tunables::asan_stack_switching was introduced, which was set entirely by cfg!(asan). This option changes codegen behavior and is required for any runtime running under ASan, so its required to match across Module/Component code serialization.

This adds an option to Config so that that a codegen Engine built without ASan can produce code (via serialization) for a runtime Engine built with Asan. This is particularly important because codegen under ASan is extremely slow.
