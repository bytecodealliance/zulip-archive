adamrk opened PR #15041 from adamrk:abk/cleanup-run_http-test-helper to bytecodealliance:main:

The run_http test helper currently takes a channel and sends the uncollected http request down that channel for the caller to see. But only a few tests actually use that and it can otherwise be difficult because the request body many never actually be read and a guest program can be left hanging if it awaits that.

This change hopefully makes run_http more intuitive by not taking the channel and in general reading the full request body. The new version run_http_get_forwarded_request can be used if the caller needs to see how the request was passed along and the new endpoint p3-test-immediate-response can be used when the test needs a response to be sent without the body being read.
