jrandolf opened PR #14800 from jrandolf:wasi-0.3.2 to bytecodealliance:main:

This updates the vendored WASIp3 WITs to the 0.3.2 release of WASI, so wasmtime-wasi and wasmtime-wasi-http now implement the 0.3.2 versions of the interfaces. Apart from version numbers the WITs are the same as 0.3.0; the only other difference is a doc comment about casing in wasi:http's fields.

Components built against 0.3.0, which includes everything Rust's wasm32-wasip3 target produces today, keep working because imports and exports are matched on semver-compatible versions. I've added a CLI test that runs the existing p3 WAT test at @0.3.0 against the new host to make sure that stays true.
