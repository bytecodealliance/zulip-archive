OutBuffer::around_pos exposes uninitialized memory

Details
Status unsound
Package zstd-safe
Version 5.0.2+zstd.1.5.2
URL https://github.com/gyscos/zstd-rs/commit/5827de2459b8ac430e87e860f00c7f3c13023833
Date 2026-10-16

OutBuffer::around_pos accepted a position past the initialized length of a
Vec&lt;u8&gt;. The next streaming call then marked everything before the
position as initialized, so safe code could read stale heap memory between
the vector's previous length and that position.

The flaw was corrected by zero-filling that gap.

See advisory page for additional details.
