This commit is a behavioral adjustment for the implementation of WASI on
Windows to disallow the : character from being anywhere within paths
provided by the guest. The purpose of this change is to fix a bug in
Wasmtime where the path ./C:foo was misinterpreted where parts of
Wasmtime would see C:foo as a normal path component and other parts
would see it as a drive-relative path which would possible move outside
of the sandbox. Windows already disallows colons in file names anyway
and blanket disallowing them additionally removes the ability to deal
with an apparent feature of NTFS which uses colons to put data in
separately named streams on disk.
