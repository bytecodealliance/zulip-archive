This commit is a few changes related to various aborts in the C API. The changes made here are:

  • Many wasm.h functions are now documented as aborting the process. This is due to the fact that wasm.h has not been updated to support wasm proposals like memory64, simd, etc. Alternatives that do not abort as wasmtime_* are recommended or added where possible.

  • Conversion to Val for components is now fallible to handle the case of invalid UTF-8 being passed from the host.

  • A minor issue related to async and callbacks was fixed.
