Followup to [1]: we shouldn't impose limits on offsets -- consistent with our "pointers are just integers" stance, and to allow algebraic simplifications/folding without edge cases, we should support arbitrary arithmetic that adds and subtracts pointer values, as long as the final value is within a stack slot.

This required adding "large offset" lowering cases for completeness, which probably won't actually be used (because our stack frame size is limited), but we want to support compiling any valid IR, so they are provided and tested here.

[1]: https://github.com/bytecodealliance/wasmtime/pull/14651#discussion_r4237927622
