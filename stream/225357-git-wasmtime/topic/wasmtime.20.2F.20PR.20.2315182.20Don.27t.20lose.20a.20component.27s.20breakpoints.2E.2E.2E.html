sansmoraxz opened PR #15182 from sansmoraxz:guest_debug_fix to bytecodealliance:main:

In a component with several core modules, turning single-stepping off removed the breakpoints in all of its modules except the last one.

The modules share one code image. When single-stepping was switched, each module reset every breakpoint site in that shared code by its own list of breakpoints, including the sites belonging to other modules. Whichever module went last decided for all of them.

With this change, each module only resets its own sites.

The test, component_breakpoint_survives_single_step, sets a breakpoint in one of two modules, turns single-stepping on and off, and checks that the breakpoint still fires. Without the fix, a breakpoint in the first module never fires.
