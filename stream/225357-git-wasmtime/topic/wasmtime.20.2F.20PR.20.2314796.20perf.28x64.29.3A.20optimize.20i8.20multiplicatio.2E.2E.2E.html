Fixes #14660.

On x64, multiplying an i8 value by a constant currently uses mulb
and can load the constant from memory. This uses a 32-bit immediate
imul instead, which gives the same low-byte result.

Byte loads remain byte-sized. Added tests for both operand orders,
wrapping results, negative constants, and inputs with unused upper bits.
