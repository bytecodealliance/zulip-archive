Extra Info

The limitation. default_aapcs_clobbers() in isa/aarch64/abi.rs says:

The upper 64 bits of v8 - v15 inclusive are also caller-saves. However, because we cannot currently represent
partial registers to regalloc2, we indicate here that every vector register is caller-save. Because this function
is used at callsites, approximating in this direction (save more than necessary) is conservative and thus safe.

This stopgap was chosen in #2254 and #2267, where a follow-up was noted so that prologues and epilogues deal only with
the lower 64 bits. In regalloc2, partial registers are out of scope (bytecodealliance/regalloc2#247).

The proposal. A function with no value wider than 64 bits loses nothing when a call clobbers only the upper
halves of v8–v15, so it can drop them from that call's clobbers without regalloc2 knowing about partial registers:

  • A new provided method, ABIMachineSpec::get_regs_partially_clobbered_by_call(callee_conv, is_exception), returns
    v8–v15 on aarch64 wherever the default AAPCS clobbers apply, and an empty set elsewhere and on other targets.

  • Callee::new computes a has_wide_values flag from the types of the function's dfg values, as it already scans
    the dynamic types. A type that the backend cannot place in registers counts as wide.

  • When the function has no wide value, gen_call_info drops partial(callee_conv) ∩ partial(caller_conv) from the
    call's clobbers.

There is no new setting and no call for the embedder to make. The other users of the static clobber sets are
unchanged and stay conservative. s390x carries the same comment and could opt in the same way.

Soundness.

  • The intersection with the caller's own convention matters for a PreserveAll caller. A call's clobbers also decide
    what the prologue saves, so such a caller still treats v8–v15 as clobbered and saves all 128 bits of them.

  • An exception edge is narrowed only where the unwinder already restores callee-saves, that is, for a SystemV or
    Apple try_call.

  • Winch, PreserveAll and Tail exception edges are unchanged.

Evidence. With the patch, two aarch64 filetests change when blessed: in call.clif and user_stack_maps.clif,
the q-register spills become mov to v8–v15, and the prologue saves d8, d11, d12 or d15 with stp or
str. Stock clif-util fails both blessed files. With the patch and the blessed files,

target/release/clif-util test cranelift/filetests/filetests

printed 1322 tests with no failure. A runtime test, 1-run.clif beside this issue, calls a function that writes
all 128 bits of v8–v15 from a caller that keeps scalars in them across the call:

target/release/clif-util test 1-run.clif

It printed 1 tests with no failure, with and without the patch. With its expected value changed from 0x17.0 to
0x18.0, it failed with actual: 0x1.7000000000000p4, which shows that the test runs.

A precise alternative would be per-value partial clobbers in regalloc2.

Extra Info

The limitation. default_aapcs_clobbers() in isa/aarch64/abi.rs says:

The upper 64 bits of v8 - v15 inclusive are also caller-saves. However, because we cannot currently represent
partial registers to regalloc2, we indicate here that every vector register is caller-save. Because this function
is used at callsites, approximating in this direction (save more than necessary) is conservative and thus safe.

This stopgap was chosen in #2254 and #2267, where a follow-up was noted so that prologues and epilogues deal only with
the lower 64 bits. In regalloc2, partial registers are out of scope (bytecodealliance/regalloc2#247).

The proposal. A function with no value wider than 64 bits loses nothing when a call clobbers only the upper
halves of v8–v15, so it can drop them from that call's clobbers without regalloc2 knowing about partial registers:

  • A new provided method, ABIMachineSpec::get_regs_partially_clobbered_by_call(callee_conv, is_exception), returns
    v8–v15 on aarch64 wherever the default AAPCS clobbers apply, and an empty set elsewhere and on other targets.

  • Callee::new computes a has_wide_values flag from the types of the function's dfg values, as it already scans
    the dynamic types. A type that the backend cannot place in registers counts as wide.

  • When the function has no wide value, gen_call_info drops partial(callee_conv) ∩ partial(caller_conv) from the
    call's clobbers.

There is no new setting and no call for the embedder to make. The other users of the static clobber sets are
unchanged and stay conservative. s390x carries the same comment and could opt in the same way.

Soundness.

  • The intersection with the caller's own convention matters for a PreserveAll caller. A call's clobbers also decide
    what the prologue saves, so such a caller still treats v8–v15 as clobbered and saves all 128 bits of them.

  • An exception edge is narrowed only where the unwinder already restores callee-saves, that is, for a SystemV or
    Apple try_call.

  • Winch, PreserveAll and Tail exception edges are unchanged.
