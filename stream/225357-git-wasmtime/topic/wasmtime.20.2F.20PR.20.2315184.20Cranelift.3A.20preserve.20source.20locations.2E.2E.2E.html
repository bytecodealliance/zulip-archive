Description

The egraph elaborator clones instructions during rematerialization and expression placement, but dfg.clone_inst does not copy the separate source-location entry. Surviving instructions can therefore lose their locations, leaving gaps in profiling attribution.

Copy non-default source locations at both clone sites. Skipping default locations avoids populating an otherwise empty source-location map.

The regression test checks locations on rematerialized constants and their cloned users. Removing either fix independently makes it fail.
