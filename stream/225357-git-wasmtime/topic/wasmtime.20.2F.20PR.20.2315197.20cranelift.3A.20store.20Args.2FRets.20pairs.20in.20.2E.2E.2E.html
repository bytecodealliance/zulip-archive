Summary

Addresses #5879 for the Args / Rets pseudo-instructions.

These lists are built once during ABI setup and never change length afterward, so storing Box<[ArgPair]> / Box<[RetPair]> inside the MachInst saves one machine word per instruction versus Vec (24 → 16 bytes for the list header on 64-bit). Builders still use Vec while collecting pairs, then call into_boxed_slice() when emitting the pseudo-inst.

Measurement

On this machine (size_of for the list headers):

Type Bytes (64-bit)
Vec<T> 24
Box<[T]> 16

So each Inst::Args / Inst::Rets that lives in the VCode heap carries a smaller header. Full end-to-end compile benchmarks are welcome if reviewers want them; this PR keeps the change focused on the type the issue called out (ArgPair / matching RetPair).

Testing
