adamrk opened PR #15027 from adamrk:abk/http-body-peek-bug to bytecodealliance:main:

When a guest passes an http request/response to the host and the body contains a host provided StreamProducer, we take the fast path of downcasting the stream to the underlying http::Body. But if the guest read from the stream before passing it on, there may be a buffer of data that was read out of the StreamProducer, but not handled by the guest.

This change ensures that that buffered data is included when downcasting to an http::Body. Otherwise it will be silently dropped.

Resolves https://github.com/bytecodealliance/wasmtime/issues/15020
