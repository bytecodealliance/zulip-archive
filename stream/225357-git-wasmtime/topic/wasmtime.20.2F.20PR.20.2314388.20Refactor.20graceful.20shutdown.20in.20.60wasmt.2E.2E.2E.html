This commit fixes an issue with the synchronization used in shutting down wasmtime serve with a ctrl-c or a --shutdown-addr option. Notably the previously used method .notify_waiters() did not work if the acceptor loops weren't actually blocked in waiting. Using tokio's Notify abstraction is a bit finnicky, so this encapsulates the shutdown state in a local mod to avoid reaching into private internals outside of this small region of code, and operations are now all under the Mutex for the shutdown entirely which should provide the synchronization necessary.
