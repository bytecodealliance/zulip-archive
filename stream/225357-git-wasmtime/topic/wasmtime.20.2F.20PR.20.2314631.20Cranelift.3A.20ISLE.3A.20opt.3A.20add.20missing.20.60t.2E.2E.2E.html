avanhatt opened PR #14631 from avanhatt:i32x2-scalar-guards to bytecodealliance:main:

With changes to include more vector logic, the ISLE verifier found several more cases related to #14566 where mid-end rules are not correctly guarded to exclude vector 64-bit vector types such as i32x2. Theiconst_s and iconst_u terms handle scalars, i128, and 128-bit vectors, so attempts to build 64-bit vector constants fail to match and cause compiler panics.

  • (#14566) (x >> k) << k -> x & mask (shifts.isle:27, shifts.isle:32) is guarded by fits_in_64 and builds an invalid iconst of vector type.
  • (~x) + x -> -1 and x + (~x) -> -1 (arithmetic.isle:333, arithmetic.isle:334) build iconst_s without guard.
  • -(~x) -> x + 1 and ~(-x) -> x - 1 (arithmetic.isle:590, arithmetic.isle:593) build iconst_u without guard.

This PR adds filetests for each and fixes with ty_int guards. Fixes #14566. Will put up verifier/spec changes as separate PR.
