To me at least the platform-specific bits are pretty bad, they're redefining structures that I'd expect to be sourced from windows-sys or libc, assuming it's the same across all unix platforms, which history has shown is rarely the case in the full limit of time, and on Windows this is doing manual path filling/manipulations which we've historically also gotten wrong and/or had bugs with in this repo too.

I'd personally be more comfortable with a mostly-works-even-if-not-always solution that's easier to integrate and more portable (like the git hash) which at least fixes the sightglass use case if not the local-testing-before-builds-are-made. For the latter use case caching is off-by-default (right?) so you'd have to otherwise opt-in explicitly to enabling it, and we might be able to document that it shouldn't be enabled in such a situation.
