This is the equivalent of bytecodealliance/wit-bindgen#1778 over here in the Wasmtime repository. In short by embedding $OUT_DIR in the proc macro it makes the build unreproducible and can reduce cache hits in larger build systems. Keep Wasmtime's debugging-only feature in parity with wit-bindgen's feature here by shuffling around how this works.

This additionally deletes the include_generated_code_from_file macro option as that's basically subsumed by debug which is a bit of a clearer name.
