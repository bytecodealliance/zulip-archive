Shared memories are disabled by default in Wasmtime, but if enabled then the following test doesn't pass. Note that the wast subcommand unconditionally enables shared memory for spec tests.

(module $a
  (memory (export "m") 1 1 shared)
  (func (export "ld") (param i32) (result i32) (i32.load (local.get 0))))
(register "a" $a)
(module $b (import "a" "m" (memory 1 1 shared)))
(assert_trap (invoke $a "ld" (i32.const 0x10000)) "out of bounds")
