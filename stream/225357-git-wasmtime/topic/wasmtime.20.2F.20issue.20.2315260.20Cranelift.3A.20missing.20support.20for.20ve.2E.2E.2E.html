Hi, this issue follows up on #14896 and the linked verification failure.

Feature

Add support for constructing 32-bit vector constants, such as i8x4, in iconst_u, together with corresponding verifier specifications.
For example, iconst_u(i8x4, 1) should splat 1 into each lane: [#x01 #x01 #x01 #x01].

Benefit

This would allow optimization rules that construct constants using iconst_u to apply to these vector types.
For example, the following rule requires a vector of ones:

; (-x) - (~x) → 1
(rule (simplify (isub ty (ineg ty x) (bnot ty x))) (iconst_u ty 1))

Implementation

Extend the vector construction path in iconst_u to support these types using splat and update its verifier spec.
