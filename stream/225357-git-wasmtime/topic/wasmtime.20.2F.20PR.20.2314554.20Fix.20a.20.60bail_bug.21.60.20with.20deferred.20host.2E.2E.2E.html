This commit fixes an issue where it was possible to hit a bail_bug! for certain signatures of host functions which receive multiple resources. The problem is that when a host task is materialized it doesn't update all active resource scopes to the new scope, only the ConcurrentState. This is detected later when resources are moved through lifting/lowering to learn that a task has been materialized.
