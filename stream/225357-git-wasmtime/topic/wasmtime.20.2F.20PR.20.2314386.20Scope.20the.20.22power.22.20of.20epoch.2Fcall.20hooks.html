alexcrichton opened PR #14386 from alexcrichton:scope-hook-state to bytecodealliance:main:

This commit changes Wasmtime's API to no longer take a StoreContextMut in epoch deadline and call-hook handlers. Discussion on #14048 and historical issues have shown that this is far too powerful of an operation given the preexisting hook points within the store. In addition to the issues discovered then there are yet more issues still within Wasmtime such as a gc() during a call hook doesn't handle ValRaws on the stack and a throw() during an epoch doesn't correctly handle the exception being thrown.

The change here is to replace StoreContextMut with a new StoreHookState structure. This structure implements AsContext and allows mutable access to the T in Store<T>, but that's it. We can add mutations over time if necessary which are safe to do, but in general this is a very limited view int o the store.

Closes #14048
