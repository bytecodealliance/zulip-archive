So, the RFC gives a couple of conditions here and we are detecting them piecemeal. To me, this means its time to create a single helper function get_request_target(&Request) -> Result<Authority>, which has rustdocs saying it enforces the full set of conditions in https://www.rfc-editor.org/info/rfc9112/#section-3.2

A server MUST respond with a 400 (Bad Request) status code to any HTTP/1.1 request message that lacks a Host header field and to any request message that contains more than one Host header field line or a Host header field with an invalid field value.

And some of that can be de-duplicated out of the p3 branch of code into that auxillary function. In the p2 branch it can just let _ = authority; so it builds without warnings when p3 disabled.
