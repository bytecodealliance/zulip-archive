Table::copy copies each element by reading it with Table::get and writing it with Table::set. For GC reference tables, Table::get creates a LIFO Rooted in the caller's current root scope. Nothing in Table::copy released those roots, so when it was called on a plain &mut Store rather than inside a RootScope, every copied object stayed rooted until the store was dropped. Repeated copies grew the root set and kept the GC heap from shrinking across collections.

Enter a GC LIFO scope around each element's get/set pair and exit it afterwards, so the temporary root is released before the next element is copied.
