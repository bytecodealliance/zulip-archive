Closes #9946.

Motivation

@tliron pointed out in #9946 that the exported resources example only gets a ResourceAny from a constructor, so it doesn't show what to do with a guest resource returned by an ordinary function, how to hand it back to the guest, or whether the host has to call resource_drop on it. The ResourceAny docs also didn't say that try_into_resource only works for host-defined resources. The ownership rules were explained in the thread, but they aren't written down in the docs or shown in the example yet. This follows @tliron's suggestion to show a resource both passed to and returned from exported functions.

Changes

  • The example's WIT gains three free functions: get-default-logger returns an owned logger, inspect-logger takes borrow<logger>, and take-logger takes an owned logger.
  • The example walks through them: it gets a returned logger, borrows it, calls a method on it, and drops it; then it constructs another logger and transfers it to the guest instead of dropping it. The comments point out that both parameter kinds are ResourceAny in Rust, so the WIT signature decides ownership, and that ResourceAny being Copy doesn't make a transferred handle reusable.
  • The ResourceAny docs are split into guest-defined, host-defined, and "Ownership and destruction" sections. The typed conversions now say they only accept host-defined resources, and the drop rule lists passing to an own parameter alongside resource_drop and conversion.

Documentation only: no runtime or public API changes. The Guest bindings in the example module gain three methods from the new WIT.

Testing

cargo test -p wasmtime --doc _6_exported_resources   # with RUSTDOCFLAGS="--cfg docsrs"

Locally: fmt, and cargo doc -p wasmtime both with and without --cfg docsrs, with no new rustdoc warnings. I also ran the existing pass_guest_back_as_borrow, manually_destroy, and resource_drop_concurrent_in_run_concurrent tests, which cover the behavior the new docs describe.

resource_drop_concurrent, which came out of @SilverMira's comment here via #14291, was added in #14362, so the drop docs there already list all three variants.
