Closes #14582.

Summary

When Table::grow is invoked with an unrooted Rooted GC reference (such as ExternRef, AnyRef, or ExnRef), ensure_matches_ty previously returned Ok(()) for top heap types without verifying that the reference was still rooted. As a result, growth proceeded and the subsequent _fill step encountered an unrooted error during into_table_gc_ref, which triggered an unwrap() panic on a grown table.

Changes

  • In Ref::_matches_ty and Ref::load_ty, call try_gc_ref(store) when matching Extern, Any, and Exn against their respective top heap types. This enforces the documented contract of matches_ty ("Returns an error if the underlying Rooted has been unrooted") upfront before table reallocation occurs.
  • In Table::_grow, propagate errors from _fill with ? instead of panicking.
  • Added a unit test in runtime::externals::table::tests verifying that Table::grow with an unrooted reference returns Err without panicking and preserves the original table size.
