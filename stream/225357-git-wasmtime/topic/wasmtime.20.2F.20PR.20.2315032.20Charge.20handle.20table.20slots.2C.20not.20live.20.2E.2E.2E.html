This commit updates the implementation originally added in #14732 to limit component model handles within a store to instead limit handle slots, not live entries. The change here is made because while limiting live entries limits memory consumption the store doesn't currently shrink preexisting vectors. This means that live entries is a proxy for the possible high watermark of memory usage but is a bit lossy because previously allocated slots are also taking up memory. The change here is to effectively never decrement the count of slots within the store since those vectors are never shrunk at this time. This is still not expected to greatly affect components in the wild since the handle limit is high enough to not hit it in typical usage.
