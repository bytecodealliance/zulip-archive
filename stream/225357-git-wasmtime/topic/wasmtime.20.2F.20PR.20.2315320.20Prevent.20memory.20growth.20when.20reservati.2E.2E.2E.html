This commit is an adjustment of the logic to grow an mmap-backed linear memory. Specifically when a memory cannot move and when the memory reservation is not page-size-aligned this means that memories may not grow to their full extent. This is required because bounds-checks assume that bytes beyond the memory_reservation tunable are all inaccessible in this scenario, but when memory_reservation is not page-size-aligned the actual capacity is beyond memory_reservation.

The fix here is to, in some situations that match what compiled code expects, to clamp the size of growth a bit more aggressively and disallow growth in situations that the compile code isn't expecting.
