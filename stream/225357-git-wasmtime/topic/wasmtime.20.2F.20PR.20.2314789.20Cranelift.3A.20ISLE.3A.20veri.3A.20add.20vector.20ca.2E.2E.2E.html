Add support in the ISLE verifier for SIMD types with explicit lane counts. This allows us to catch ISLE rules that should exclude vector types but do not (e.g., #14566, #14631, #14701).

Introduce lanemap and similar forms into the ISLE spec lang, update CLIF terms to use these to indicate when specs apply per lane (e.g., iadd does not carry between lanes), add support for vector types into inference and the verifier. Add new veri filetests.

Note the Type model change alters most SMT queries, so this will be slow on the CI cache.
