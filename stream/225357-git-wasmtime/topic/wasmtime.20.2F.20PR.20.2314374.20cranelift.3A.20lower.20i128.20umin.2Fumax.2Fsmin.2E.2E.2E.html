Summary

The mid-end rewrites select(icmp ugt/ult/..., a, b) into integer min/max. On x86_64 those forms were only lowered for fits_in_64, so optimized i128 code hit:

Unsupported feature: should be implemented in ISLE: inst = umin.i128 ...

Fix

Lower umin / umax / smin / smax for $I128 through the existing i128 emit_cmp + lower_select path (same shape as AArch64's scalar-int lowering).

Test plan

  • New compile coverage: isa/x64/iminmax-i128.clif (includes the #13790 select→umin case)
  • New runtest: runtests/issue-13790-umin-i128.clif
  • Extended: runtests/i128-min-max.clif now includes target x86_64

Fixes #13790
