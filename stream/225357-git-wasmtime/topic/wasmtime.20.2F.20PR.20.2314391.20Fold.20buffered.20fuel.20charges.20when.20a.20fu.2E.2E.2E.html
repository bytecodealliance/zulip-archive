Instantiation-time fuel is dropped for modules with no start function.

A module with a multi-op const-expr global initializer reports 1 unit of fuel
consumed instead of 4. Adding an empty start function to the same module makes it
report the expected 6.

Those charges accumulate in fuel_consumed. Wasm functions fold that buffer into
fuel_var through the trailing end operator, but the module startup function is
synthesized and has no end, and module_start, the other place that flushes the
buffer, is only emitted when start exists. So the buffer is dropped.

fuel_function_exit now folds the buffer before saving. For functions translated
from wasm this is a no-op.
