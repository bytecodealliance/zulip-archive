fitzgen opened PR #14962 from fitzgen:transfer-borrow-to-owner to bytecodealliance:main:

When passing a resource borrow to the instance that defined the resource type, we do not put the borrow into the instance's table, but instead return the resource's rep directly. We actually statically know whether we are in this case or not, so this commit makes us emit a separate libcall that skips the dynamic check of whether we can save work or not and just does the right thing automatically.

This is not really a win by itself in practice, but is meant instead to start paving the way for an eventual inline fast path for this scenario.
