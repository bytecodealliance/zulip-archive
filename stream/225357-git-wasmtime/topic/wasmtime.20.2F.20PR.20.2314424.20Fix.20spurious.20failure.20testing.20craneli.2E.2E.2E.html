This commit is an attempt at fixing the spurious failure that happened at https://github.com/bytecodealliance/wasmtime/actions/runs/36156707251/job/108142997495. While I don't know exactly what happened the hunch is that one thread of the process opened up a shell script for writing, another thread in the process fork'd which then keeps the fd open for writing before any exec`, and then the original thread tries to execute the file. This then fails because the fd is open for writing and thus can't be opened for execution.

The fix here is to avoid writing something to the filesystem and fiddle with sh arguments to pass the script in differently.
