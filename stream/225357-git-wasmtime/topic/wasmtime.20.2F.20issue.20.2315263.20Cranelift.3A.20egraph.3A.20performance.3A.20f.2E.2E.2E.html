.clif Test Case

A chain of N blocks, each dominated by the one before it. Each block divides its value by the constant 3 and either
returns or passes the value plus 1 to the next block. Here N = 2:

function %chain(i64) -> i64 {
block0(v0: i64):
    v1 = iconst.i64 3
    v2 = iconst.i64 1
    jump block1(v0)

block1(v3: i64):
    v4 = srem v3, v1
    v5 = iadd v3, v2
    brif v4, block3(v5), block2

block2:
    return v3

block3(v6: i64):
    v7 = srem v6, v1
    v8 = iadd v6, v2
    brif v7, block5(v8), block4

block4:
    return v6

block5(v9: i64):
    return v9
}

The following script writes the same function at any N:

#!/bin/sh
# Writes a chain of N blocks, each returning its value if the value is divisible by 3 and otherwise passing on the
# value plus 1.
n=${1:-4}
printf 'function %%chain(i64) -> i64 {\nblock0(v0: i64):\n    v1 = iconst.i64 3\n    v2 = iconst.i64 1\n    jump block1(v0)\n'
i=1
while [ $i -le $n ]; do
  v=$((3 * i))
  printf '\nblock%d(v%d: i64):\n    v%d = srem v%d, v1\n    v%d = iadd v%d, v2\n    brif v%d, block%d(v%d), block%d\n\nblock%d:\n    return v%d\n' \
    $((2 * i - 1)) $v $((v + 1)) $v $((v + 2)) $v $((v + 1)) $((2 * i + 1)) $((v + 2)) $((2 * i)) $((2 * i)) $v
  i=$((i + 1))
done
printf '\nblock%d(v%d: i64):\n    return v%d\n}\n' $((2 * n + 1)) $((3 * n + 3)) $((3 * n + 3))

Steps to Reproduce

  • First, build clif-util from wasmtime v50.0.0, the release that ships cranelift-codegen 0.137.0:
    curl -L https://github.com/bytecodealliance/wasmtime/archive/refs/tags/v50.0.0.tar.gz | tar xz cd wasmtime-50.0.0 cargo build --release -p cranelift-tools --bin clif-util

  • Then, compile the function at four sizes, printing the pass timings with -T, and the instructions retired and
    peak memory of the whole clif-util process with macOS's /usr/bin/time -l:
    for n in 2048 4096 8192 16384; do sh 4-gen.sh $n > chain.clif echo "N=$n" /usr/bin/time -l target/release/clif-util compile --target aarch64 --set opt_level=speed -T chain.clif 2>&1 | grep -E 'Egraph|instructions retired|maximum resident' done

  • Then, apply the patch under Extra Info, build again, and run the same loop.

Expected Results

Compile time grows linearly with N. With the patch, the instructions retired by clif-util double with each doubling
of N, and at N = 16,384 the egraph pass takes 0.23 s:

N Egraph pass Instructions retired Peak memory
2,048 0.025 s 0.86G 34 MB
4,096 0.046 s 1.65G 61 MB
8,192 0.102 s 3.38G 117 MB
16,384 0.227 s 6.95G 235 MB

Actual Results

Compile time grows quadratically with N: at N = 16,384 the egraph pass takes 1.28 s, and with the patch 0.23 s. The
instructions retired by clif-util grow 2.6, 3.0 and 3.3 times per doubling of N, while peak memory only doubles:

N Egraph pass Instructions retired Peak memory
2,048 0.042 s 1.27G 34 MB
4,096 0.114 s 3.26G 61 MB
8,192 0.368 s 9.83G 117 MB
16,384 1.283 s 32.73G 235 MB

The pass times are the first column of -T. The instructions retired include parsing, verification and every other
pass. Each figure is from one run, on a machine whose load average was about 7 at the time.

Versions and Environment

Cranelift version or commit: cranelift-codegen 0.137.0, with regalloc2 0.15.2, built into clif-util from wasmtime
v50.0.0 (commit ebe5e8df1f4e12c5fc2f5954926881d8d61367d8) with rustc 1.98.0, --release and default features.

Operating system: macOS 26.6.2 (build 25G83).

Architecture: arm64 (Apple M5 Pro), compiling for --target aarch64.

Extra Info

OptimizeCtx::depth_of_block_in_gvn_map finds a block's level on the GVN map's scope stack by scanning
gvn_map_blocks from the top. insert_pure_enode calls it for every new pure node, at the block where the node is
available. A node available near the root scans nearly the whole stack, and the stack is as deep as the dominator
tree. Here, each srem by a constant is rewritten into a multiply by a magic number, whose constants are available at
the entry block, so each of the N blocks scans a stack about as deep as its own position.

The patch records each block's level as the block is pushed, and looks it up instead.
