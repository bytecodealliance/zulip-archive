Add new mid-end opt rules:

  • x - (x & M) ==> x & ~M
  • (x - (y & M)) + y ==> (y & ~M) + x
  • (x + y) - (x & M) ==> (x & ~M) + y
  • ((1 << k) + 1) * y ==> (y << k) + y
  • (x + C1) - (y + C2) ==> (C1 - C2) + (x - y) and related add/sub forms
  • uextend(x) == 0 ==> x == 0
  • uextend(x) == uextend(y) ==> x == y
  • (x == y) ^ 1 ==> x != y
  • x >u (x - 1) ==> x != 0, and its dual(<u)
  • (c ? x : y) + (c ? p : q) ==> c ? (x + p) : (y + q)
  • (c ? C1 : C2) & M ==> c ? (C1 & M) : (C2 & M)
  • (x == 0) ? y : (x + y) ==> y + x, and its dual (!=)
  • (c ? C1 : C2) << K ==> c ? (C1 << K) : (C2 << K)

Thanks!
