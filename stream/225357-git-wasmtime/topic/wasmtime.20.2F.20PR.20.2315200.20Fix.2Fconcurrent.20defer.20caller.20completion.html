GamePad64 edited PR #15200:

Found in the wild: a Servo-based renderer component (web page → markdown) running ~15 cooperative guest threads under wasip3, driven by repeated calls into one component instance. Within ten cold runs the second call into the instance stopped returning: the instance's do_not_enter latch stayed set and every later call was refused. Two scheduler defects with independent triggers, two commits.

Commit 1 — poll_until completed the caller future as soon as it polled Ready, even with work items queued and in-flight ack tasks unpolled. The caller returns, the ack task never gets polled, the guest fiber never resumes, exit_instance never runs. Now the caller future is polled at most once per pass; if it's ready while a switch item or high-priority work is pending, completion is deferred until the urgent queues are empty and ConcurrentState::futures has fully drained.

Commit 2 — a task returning Exit leaves stale ResumeThread/GuestCall items in the queues and switch slots; resuming one runs guest code past the task's end and strands a fiber on thread.suspend. On exit, both queues are retain-filtered and the switch slots cleared, scoped to the exiting thread — a task can have sibling threads still live (e.g. a thread.new child that hasn't run yet), and purging the whole task's items deadlocks the event loop waiting for a task.return that never happens. ResumeFiber items are left alone: dropping a never-started StoreFiber via retain would trip the dispose assertion in Drop.

Both fixes were found and verified on v50.0.1 and hand-ported to main (the file moved from src/runtime/component/ to crates/wasmtime/src/runtime/component/). Commit 2's scope was corrected from task to thread after task-deletion.wast caught it in CI.

Testing: with both fixes, sequential second calls into one instance complete; a full render matrix and 10x single-call runs are green through a real host runtime. Before, the second call wedged within ten runs. No test added to the suite: the trigger needs a ~160 MB component; happy to shrink it with guidance.
