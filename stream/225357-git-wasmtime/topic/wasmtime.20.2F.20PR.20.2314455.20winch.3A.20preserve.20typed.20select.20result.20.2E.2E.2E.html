macovedj opened PR #14455 from macovedj:winch-typed-select-stack-maps to bytecodealliance:main:

Winch records a select result using the second operand’s internal type, even for a typed select with a declared result type. In #14451, that operand is ref.null extern, which Winch represents internally as I32. When the condition chooses the live externref from the first operand, the value is correct, but Winch still records the result as I32. The next call’s stack map then omits the live reference, so a collector can lose it.

This PR records a typed select result using its declared type and adds x86-64 and AArch64 stack-map tests, plus runtime tests for all collectors.

Fixes #14451.
