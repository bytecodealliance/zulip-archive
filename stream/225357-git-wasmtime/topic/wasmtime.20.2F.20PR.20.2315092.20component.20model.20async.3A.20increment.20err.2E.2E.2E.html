Summary

Fixes bytecodealliance/wasmtime#14674.

When an error-context handle is transferred across component instances via an async future or stream, lowering it into the recipient instance inserts a local handle entry pointing to the underlying global error context table. However, lower_error_context_to_index previously omitted incrementing the cross-subcomponent global_ref_count.

As a consequence, when the recipient instance subsequently invoked error-context.drop, the global reference count was decremented to zero prematurely, deleting the global error context tracking while the sending instance still retained its handle.

This patch updates lower_error_context_to_index to increment the global reference count on insertion, mirroring the semantics of error_context_transfer.

Testing

Added regression test tests/misc_testsuite/component-model/async/error-context-future.wast, verifying that dropping the received error-context in a recipient instance does not invalidate or break subsequent drops in the sender.
