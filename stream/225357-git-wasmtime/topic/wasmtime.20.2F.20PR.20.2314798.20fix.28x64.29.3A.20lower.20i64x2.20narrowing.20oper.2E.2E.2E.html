Fixes #4734.

The x64 backend was missing the general snarrow and unarrow lowerings for i64x2 inputs. As a result, valid i64x2 -> i32x4 operations failed during compilation.

This adds SSE2-compatible lowerings that:

  • Saturate signed values for snarrow.
  • Treat unarrow inputs as signed i64 values and clamp them to [0, u32::MAX].
  • Preserve the expected lane order.
  • Keep the existing optimized conversion-specific lowerings.

Tests cover saturation boundaries, negative values, lane ordering, loaded values, and live inputs.
