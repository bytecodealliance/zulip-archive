When a StreamReader<T> or FutureReader<T> is lowered into a guest, typecheck_lowered_transmit checks the transmit's origin against the destination payload type. The type T has already been checked against the payload type, so this change allows the dynamic check to be elided in the cases when we can rely on the static check that was already done.

There are 3 cases to consider:

  1. A StreamReader<T> was directly created in the host by a Producer with P::Item == T. This case is marked with a bool tag in the HostResourceIndex and no further checks are needed.

  2. A StreamReader<T> was created by the host, but has been passed through a guest and may have had its type loosened (e.g. a StreamReader<StreamReader<String>> became a StreamReader<StreamAny>). In this case, we compare the TypeId of the Producer's P::Item against T and skip further checks if they match. If they don't match we dynamically run the Producer's typecheck.

  3. A StreamAny always runs the dynamic typecheck.

This shows a ~5% improvement in the p3_http_proxy benchmark:
