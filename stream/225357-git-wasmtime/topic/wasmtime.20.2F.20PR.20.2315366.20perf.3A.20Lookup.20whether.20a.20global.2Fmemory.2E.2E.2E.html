This has been discussed in a private conversation on zulip with @alexcrichton and @fitzgen .

During compilation, cranelift calls Module::is_exported_memory in memory_alias_region for every Wasm instruction that accesses memory. That method iterates through all exports, so if there are many of those and many accesses, it can slow down compilation significantly.

This PR addresses that by making Module.exports a struct that keeps some auxiliary sets and keeps them in sync with the exports map. The public interface of the new struct ModuleExports exposes just what's currently needed by callers, but can be easily extended.
