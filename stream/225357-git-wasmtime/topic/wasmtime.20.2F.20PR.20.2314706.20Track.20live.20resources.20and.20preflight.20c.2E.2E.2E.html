macovedj opened PR #14706 from macovedj:component-async-table-capacity to bytecodealliance:main:

Component stream and future construction inserts a shared state and two endpoint handles into the resource table. If only one or two slots remain, construction can return ResourceTableError::Full after inserting entries that the caller receives no handles to clean up. Failed construction therefore continues consuming table capacity.

This PR checks the complete entry requirement before starting these allocations. It applies equivalent checks to guest tasks, explicit threads, and deferred host tasks, placing them before relevant task or task-group reference changes. Insufficient capacity then rejects the checked allocation batch before it creates partial entries.

It also adds constant-time ResourceTable::len() and makes the existing is_empty() constant-time using centralized live-entry accounting. This supports repeated occupancy checks without scanning the backing table.
