This commit updates our CI and how Rust is installed. Notably the forced 1.$n.0 toolchain is changed to 1.$n which means that we'll automatically get the latest patch update in CI to Rust toolchains. This change is motivated by #15216 where Wasmtime's 50.0.0 release was built with Rust 1.99.0 which contained a miscompile for bool-returning functions. This miscompile affects users of the C API and is fixed with Rust 1.99.1. Rust 1.99.1 was released before Wasmtime 50.0.0 was released so in theory we should have gotten the fix, but our CI configuration meant that patch releases of Rust are never used on CI.
