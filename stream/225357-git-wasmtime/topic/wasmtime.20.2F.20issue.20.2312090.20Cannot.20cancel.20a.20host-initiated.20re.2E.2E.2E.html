To articulate this a bit more now that I've got more experience: here's a set of relate things you can't do with the current API:

  • Start reading a {Future,Stream}Reader then cancel it to get back a {Future,Stream}Reader to pass back into wasm.
  • Start reading a FutureReader and somehow return "closed" to the caller. The current API of FutureConsumer is such that "closed" is just not an option.
