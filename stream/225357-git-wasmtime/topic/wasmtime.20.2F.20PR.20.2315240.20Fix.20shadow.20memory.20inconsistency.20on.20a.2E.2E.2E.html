alexcrichton opened PR #15240 from alexcrichton:fix-shadow-memory-growth to bytecodealliance:main:

This commit fixes a possible issue with shadow memories and watchpoints where while both memories are validated up-front to be able to satisfy the allocation request it's still possible for the OS to deny growth of one but not the other. This fixes a situation where the main linear memory was able to grow but the shadow memory failed growth. The fix here is to shuffle around growth for the shadow memory, growing it first, so the updates after the main linear memory is infallible.
