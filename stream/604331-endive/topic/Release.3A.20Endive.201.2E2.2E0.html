Topic: Release: Endive 1.2.0

andreaTP (Oct 30 2026 at 16:02):

Endive 1.2.0 is out, thanks also to a lot of new contributions from the community :tada:

  • SIMD instructions are supported by default in the interpreter: every Java from 11 up, nothing to add or configure.
  • Major redline advancements addressing most of the early adopters' feedback, and showing impressive numbers: native memory is released with the Java objects that use it, so close() is optional; nothing is compiled at runtime; tables shared between instances just work.
  • Speed-ups in the memory support for the Threads proposal, consistent atomics across memory implementations, and compileModule() to shed the heap compiled modules used to retain.
  • The Component Model is having great momentum and is starting to be usable: parser, Canonical ABI, bindgen, linking and WASI 0.2 hosts in https://github.com/roastedroot/endive-cm
  • We intend to drop Java 11; tell us on https://github.com/bytecodealliance/endive/issues/250 if that affects you.
